# export

## Overview

Request bodies of `ExportRoutes`: the export settings chosen in the export dialog and the preview of the label file they would write.

## Components

| Component | Description |
| --- | --- |
| [preview.py](./preview.py) | `ExportPreviewBody` describes the export chosen in the export dialog, whose label file is previewed. |
| [settings.py](./settings.py) | `ExportBody` describes the export chosen in the export dialog. |
