# class-tree

## Overview

Rows and model of the class tree in the class editor.

## Components

| Component | Responsibility |
|---|---|
| [ClassRow.tsx](ClassRow.tsx) | Row of a class. |
| [DrawingRow.tsx](DrawingRow.tsx) | Row of a point, box or exemplar prompt drawn on a picture, with a thumbnail of the drawing. |
| [InlineInput.tsx](InlineInput.tsx) | Inline text input for renaming and adding. |
| [PhraseRow.tsx](PhraseRow.tsx) | Row of a class prompt. |
| [PromptKindTile.tsx](PromptKindTile.tsx) | Colored tile marking the kind of a prompt (text, image, point, box, exemplar). |
| [ReferenceRow.tsx](ReferenceRow.tsx) | Row of a reference image. |
| [classTreeModel.ts](classTreeModel.ts) | Tree rows, editing state and drag payloads. |
