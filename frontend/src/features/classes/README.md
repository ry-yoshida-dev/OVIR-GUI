# classes

## Overview

Class list editing and the dialogs around it.

## Components

| Component | Responsibility |
|---|---|
| [ClassEditor.tsx](ClassEditor.tsx) | Tree editor of classes, their prompts and reference images. |
| [ClassSetDialog.tsx](ClassSetDialog.tsx) | Saves and loads class sets. |
| [ClassTextDialog.tsx](ClassTextDialog.tsx) | Edits the class list as text. |
| [LabelModeSwitch.tsx](LabelModeSwitch.tsx) | Chooses whether a classified picture gets one class or every class reaching its minimum. |
| [ReferenceDialog.tsx](ReferenceDialog.tsx) | Adds reference images with boxes to a class. |
| [class-tree/](class-tree/README.md) | Rows and model of the class tree. |
