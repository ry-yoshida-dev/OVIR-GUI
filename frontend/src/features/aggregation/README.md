# aggregation

## Overview

Editor for how classification scores are aggregated over prompt templates and prompts.

## Components

| Component | Responsibility |
|---|---|
| [AggregationDiagram.tsx](AggregationDiagram.tsx) | Diagram of the aggregation steps. |
| [AggregationField.tsx](AggregationField.tsx) | Setting row that summarizes the aggregation and opens its panel. |
| [AggregationMethodPicker.tsx](AggregationMethodPicker.tsx) | Picker of an aggregation method with its formula. |
| [AggregationPanel.tsx](AggregationPanel.tsx) | Panel editing the aggregation steps. |
