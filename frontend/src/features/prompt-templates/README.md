# prompt-templates

## Overview

Prompt template editing.

## Components

| Component | Responsibility |
|---|---|
| [TemplateField.tsx](TemplateField.tsx) | Setting row showing the chosen template. |
| [TemplatePanel.tsx](TemplatePanel.tsx) | Panel choosing and editing templates. |
| [TemplateText.tsx](TemplateText.tsx) | A template read as a sentence, with a mark where the prompt goes. |
| [TemplateWordsField.tsx](TemplateWordsField.tsx) | Field editing the words of a template. |
