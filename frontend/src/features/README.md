# features

## Overview

UI grouped by feature. Each sub-directory holds the components and hooks of one area of the app.

## Components

| Component | Responsibility |
|---|---|
| [aggregation/](aggregation/README.md) | Editor for how classification scores are aggregated over templates and prompts. |
| [canvas/](canvas/README.md) | Picture viewer of the center pane: findings, zoom, scores and view settings. |
| [classes/](classes/README.md) | Class list editing, class sets, class text and reference images. |
| [embedding/](embedding/README.md) | Control of the app by an embedding page. |
| [export/](export/README.md) | Export dialog. |
| [file-browser/](file-browser/README.md) | Browser for files and folders on the server. |
| [findings/](findings/README.md) | Result table, its filters, and the compared result profiles. |
| [gallery/](gallery/README.md) | Classification and picture galleries. |
| [inference/](inference/README.md) | Run controls and inference settings. |
| [media/](media/README.md) | Media list, upload and navigation. |
| [models/](models/README.md) | Model selection, model library and license consent. |
| [picture-prompts/](picture-prompts/README.md) | Drawing prompts (boxes, points) on a picture. |
| [playback/](playback/README.md) | Video playback with findings, timeline and video findings panel. |
| [prompt-templates/](prompt-templates/README.md) | Prompt template editing. |
| [review/](review/README.md) | Review panel: score thresholds and distributions. |
| [shell/](shell/README.md) | App frame: task tabs, the three panes, status bar, notices and app dialogs. |
| [statistics/](statistics/README.md) | Statistics dialog. |
