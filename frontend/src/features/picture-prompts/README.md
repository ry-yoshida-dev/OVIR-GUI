# picture-prompts

## Overview

Prompts drawn on a picture (boxes and points).

## Components

| Component | Responsibility |
|---|---|
| [PromptOverlay.tsx](PromptOverlay.tsx) | Prompts drawn over the picture. |
| [PromptToolbar.tsx](PromptToolbar.tsx) | Toolbar for drawing prompts. |
| [usePicturePromptEditor.tsx](usePicturePromptEditor.tsx) | State and actions of the picture prompt editor. |
