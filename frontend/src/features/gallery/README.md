# gallery

## Overview

Galleries of the center pane.

## Components

| Component | Responsibility |
|---|---|
| [ClassificationGallery.css](ClassificationGallery.css) | Styles shared by both galleries. |
| [ClassificationGallery.tsx](ClassificationGallery.tsx) | Gallery of classified pictures grouped by class. |
| [FindingOverlay.tsx](FindingOverlay.tsx) | Findings drawn over a gallery tile. |
| [GalleryInspector.tsx](GalleryInspector.tsx) | Detail panel of the selected classified picture. |
| [PictureGallery.css](PictureGallery.css) | Styles of the picture gallery. |
| [PictureGallery.tsx](PictureGallery.tsx) | Gallery of pictures with their findings. |
| [PictureGalleryInspector.tsx](PictureGalleryInspector.tsx) | Detail panel of the selected picture. |
| [ScoreSpectrum.tsx](ScoreSpectrum.tsx) | Ranked class scores of a tile as bars. |
| [useMaskOutlines.ts](useMaskOutlines.ts) | Loads mask outlines of gallery findings. |
