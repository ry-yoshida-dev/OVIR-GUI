# inference

## Overview

Run controls and inference settings.

## Components

| Component | Responsibility |
|---|---|
| [InferControl.tsx](InferControl.tsx) | Run button and its options. |
| [InferenceModeSettings.tsx](InferenceModeSettings.tsx) | Settings of the inference mode. |
| [InferenceSettings.tsx](InferenceSettings.tsx) | Inference settings of the current task. |
| [useInfer.ts](useInfer.ts) | Starts inference in the chosen mode; a whole-video run starts from the shown frame and plays along. |
